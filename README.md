# Arkidian Canvas

Arkidian Canvas는 현재 Markdown 문서를 확대/이동 가능한 캔버스로 열어 주는 Obsidian 플러그인입니다.

문서의 제목 구조를 기준으로 내용을 카드처럼 배치하고, 각 섹션과 임베드의 관계를 캔버스와 레이어 패널에서 함께 탐색할 수 있게 합니다.

## 주요 기능

- Markdown 제목 구조를 캔버스 카드로 시각화
- 마우스 휠 확대/축소와 드래그 이동
- 섹션, 본문 블록, Markdown 임베드 선택 및 탐색
- 좌측 레이어 패널에서 문서 구조 확인
- 카드 위치와 너비 조정
- 더블 클릭으로 원본 Markdown 위치 열기

## 상태

초기 개발 중인 플러그인입니다. 현재는 Markdown 문서를 캔버스에서 읽고 탐색하는 경험을 중심으로 구현하고 있습니다.
